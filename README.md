## 🚀 Descripción

F&Y Solutions ofrece servicios de asistencia virtual especializada adaptados para agentes de seguros de salud, centrándose en programas de Medicaid, licencias en múltiples estados y cumplimiento con el CMS. Este proyecto es un sitio web profesional, moderno y adaptativo diseñado para mostrar sus servicios, generar confianza y facilitar el contacto con los clientes.

## ✨ Características

- **Asistentes Virtuales Especializados** 🧑‍💼: Profesionales capacitados exclusivamente en el ecosistema de Medicaid (elegibilidad, inscripción, renovaciones, gestión de casos).
- **Gestión de Licencias en 50 Estados** 🗺️: Gestión integral de licencias de seguros de salud, incluyendo solicitudes, renovaciones, educación continua y correcciones con departamentos estatales.
- **Cumplimiento y Auditoría CMS** ✅: Servicios para garantizar que las operaciones se alineen con los requisitos de los Centros de Servicios de Medicare y Medicaid (CMS), preparando a la empresa para auditorías federales.
- **Operaciones Seguras y Reglamentarias** 🔒: Énfasis en el cifrado de datos (TLS 1.3, AES-256), alineación con las directrices de CMS, acuerdos de confidencialidad (NDA) y auditorías internas periódicas.
- **Diseño Moderno y Adaptativo** 📱: Una interfaz atractiva y fácil de usar que se adapta sin problemas a todos los dispositivos.
- **Formulario de Contacto Interactivo** ✉️: Formulario fácil de usar para consultas, con Python para la validación del lado del cliente y la gestión de envíos.
- **Opciones de Contacto Directo** 📞: Integración con WhatsApp y función de copia de correo electrónico con un solo clic.
- **Pie de Página Dinámico** 📅: Actualiza automáticamente el año actual para la información de derechos de autor.

## 🛠️ Tecnologías Utilizadas

- **Frontend / Backend**: HTML, CSS, Python
- **Estilos**: CSS personalizado con variables CSS para temas y principios de diseño adaptativo (*responsive*).
- **Fuentes**: Google Fonts (Inter)
- **Iconos**: Iconos SVG integrados directamente en el HTML.

## 📦 Instalación

Este es un proyecto estructurado con HTML, CSS y Python. No requiere de una instalación compleja. Simplemente clona el repositorio y abre el archivo `templates/index.html` en tu navegador web.

```bash
git clone [https://github.com/sebasmontero7/PaginaFY.git](https://github.com/sebasmontero7/PaginaFY.git)
cd PaginaFY
open templates/index.html
```
